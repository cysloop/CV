حزمة إصلاح موقع السيرة الذاتية — cysloop/CV

ضع محتويات هذه الحزمة مباشرةً في جذر المستودع CV/، مع الحفاظ على أسماء المجلدات والمسارات كما هي. لا ترفع ملف ZIP نفسه، ولا تنقل الملفات من site/ إلى الجذر.

الشكل المطلوب داخل المستودع:
CV/
├── .github/
│   └── workflows/
│       └── static.yml
└── site/
    ├── index.html
    ├── .nojekyll
    ├── manus-routes.json
    └── assets/
        ├── ملفات JavaScript وCSS المبنية
        ├── cyber-skull.jpg
        └── mohammed-fadhl-cv.pdf

إذا أردت استبدال ملفات المستودع القديمة كلها، احذف الملفات القديمة فقط ثم انسخ محتويات الحزمة إلى مجلد المستودع المحلي CV/. لا تحذف مجلد Git المخفي .git ولا تحذف المستودع نفسه. استبدل الملف الموجود في .github/workflows/static.yml واترك المجلدات كما هي.

بعد نسخ الملفات إلى مجلد المستودع، افتح الطرفية داخله وشغّل:

git add -A
git commit -m "Replace with working CV site"
git push origin main

سير العمل المرفق ينشر المجلد site/ فقط، ولا يحتاج package.json أو pnpm-lock.yaml أو خطوة بناء. بعد الدفع، افتح GitHub ثم Actions وانتظر نجاح Deploy static CV to GitHub Pages. تأكد أيضًا أن Pages يستخدم GitHub Actions كمصدر للنشر.
